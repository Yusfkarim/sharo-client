# شاڕۆ | Sharo Super App
**ناسێنەری پاکێج (Bundle ID):** `com.sharo.app`  
**فرەیمۆڕک:** Flutter 3.24.5 / Dart 3.5.4  
**مۆڵەت (License):** MIT License (Yusfkarim / Sharo Super App Ecosystem)

شاڕۆ سوپەر ئەپ، پلاتفۆرمێکی پێشکەوتووی نیشتمانییە بۆ داواکردنی خێرای خواردن، بازاڕکردنی سوپەرمارکێت، تەکسی و گواستنەوەی VIP، و کارگۆ و بارهەڵگر لە سەرانسەری سلێمانی و کوردستان بە بەرزترین ستانداردی نێودەوڵەتی.

---

## تایبەتمەندییە سەرەکییەکان
- **دیزاینی سەردەمی و مۆدێرن:** دیزاینێکی بێ وێنە بە فۆنتە ڕەسەنەکانی کوردی `Bahij` و `NRT` لەگەڵ شێوازی کارتی مۆدێرن، سێبەری نەرم، و پالتەی ڕەنگی پڕتەقاڵی وزەبەخش (`#FF5A36`).
- **تۆڕی دەوڵەمەندی خزمەتگوزارییەکان:**
  - چێشتخانە و فاست فوودی ناودار (کەیف، برگرزۆن، و هتد).
  - سوپەرمارکێتی فرێشی ڕۆژانە بە سەوزە، میوە و شیرەمەنی.
  - شاڕۆ ڕاید (تەکسی ئاسایی، VIP، و بارهەڵگر) بە ڕەیتینگی شۆفێر و ژمارەی تابلۆ.
  - خەڵاتی بەردەوام و کۆپۆنی داشکاندن (`SHARO2026`).
- **بەدواداچوونی پێنج قۆناغی ڕاستەوخۆ (Live Stepper):**
  1. تۆمارکردنی داواکاری لە سێرڤەر.
  2. دەستپێکردنی ئامادەکردن لە چێشتخانە.
  3. ئامادەبوونی پاکێج بۆ وەرگرتن.
  4. کاپتن لە ڕێگایە بەرەو کڕیار بە پەیوەندی تەلەفۆن.
  5. گەیشتن و ڕادەستکردنی سەرکەوتوو.
- **جزدانی شاڕۆ (Sharo Wallet):** کۆکردنەوەی کاشباک و پڕکردنەوەی خێرای باڵانس.

---

## مۆڵەتە یاسایی و سیستەمییەکان (Android Permissions)
- `android.permission.INTERNET`: پەیوەندی بە سێرڤەری سەرەکی کلاود.
- `android.permission.ACCESS_FINE_LOCATION` و `ACCESS_COARSE_LOCATION`: دیاریکردنی وردی ناونیشان بە GPS.
- `android.permission.CALL_PHONE`: پەیوەندی بە کاپتن و پشتیوانی شاڕۆ.
- `android.permission.POST_NOTIFICATIONS`: ئاگاداری ڕاستەوخۆی گۆڕانی دۆخی داواکاری.
- `android.permission.VIBRATE` و `android.permission.WAKE_LOCK`.
